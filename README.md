# Fiches Daggerheart (Owlbear Rodeo)

## Installer
1. Héberge ce dossier tel quel (GitHub Pages, Netlify, Cloudflare Pages…).
2. Owlbear Rodeo > profil > Extensions > Add Extension > colle `https://ton-site/manifest.json`.
3. Test local : `npx serve --cors .` puis `http://localhost:3000/manifest.json`.

## Utiliser
- Clic droit sur un token > « Fiche Daggerheart » : le panneau s'ouvre en haut à gauche.
- Colle le lien Demiplane de la fiche : elle est liée au token.
- PV, stress, espoir, évasion et armure sont modifiables à la main et sauvegardés sur le token.

## Brancher l'API Demiplane
Voir `config.js` et `worker.js`.
